Quick Start Examples
// List all bundles
const response = await fetch('https://YOUR-BACKEND.up.railway.app/api/bundles');
const { data } = await response.json();

// Purchase a bundle (requires agent token)
const order = await fetch('https://YOUR-BACKEND.up.railway.app/api/bundles/purchase', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': 'Bearer YOUR_API_KEY'
  },
  body: JSON.stringify({
    bundleId: 'BUNDLE_ID',
    recipientPhone: '0244123456',
    network: 'MTN',
    paymentMethod: 'wallet'
  })
});
import requests

headers = {"Authorization": "Bearer YOUR_API_KEY"}

# List bundles
bundles = requests.get(
    "https://YOUR-BACKEND.up.railway.app/api/bundles"
).json()

# Purchase a bundle
order = requests.post(
    "https://YOUR-BACKEND.up.railway.app/api/bundles/purchase",
    json={
        "bundleId": "BUNDLE_ID",
        "recipientPhone": "0244123456",
        "network": "MTN",
        "paymentMethod": "wallet"
    },

).json()
# List all bundles
curl https://YOUR-BACKEND.up.railway.app/api/bundles

    "bundleId": "BUNDLE_ID",
    "recipientPhone": "0244123456",
    "network": "MTN",
    "paymentMethod": "wallet"
  }'

Frequently Asked Questions
How long does data delivery take?

MTN: 1 minute to 2 hours. AirtelTigo iShare: Instant. AirtelTigo BigTime and Telecel: 1 minute to 1 hour. During network congestion it may take slightly longer.

My order is stuck on "Processing" — what do I do?

Wait up to 2 hours. If still not delivered, contact us on WhatsApp with your order reference number and we'll resolve it immediately.

Can I get a refund if delivery fails?

Yes. If we are unable to deliver your order after 2 hours, the full amount will be credited back to your wallet automatically.

How do I top up my wallet?

Go to 💼 Wallet → click "Top Up Wallet" → choose amount → pay via Paystack (supports MoMo, Visa, Mastercard). Your wallet is credited instantly after payment.

What SIM types are NOT supported?

Turbonet, Merchant SIM, EVD SIM, Broadband SIM, Blacklisted SIM, Roaming SIM, and Inactive Numbers are not supported. Ensure the number is an active regular SIM on the correct network.

How do I earn commission?

You earn a percentage commission on every bundle you sell. Your commission rate increases as you move up agent ranks (Starter → Bronze → Silver → Gold). Check 👥 AFA for your current rate.
